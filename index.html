Bunk & Learn Hub — Interactive Computer Science Lab Simulator

Free, open-source, browser-based CS lab tools for B.Tech students at Shri Ramswaroop Memorial University (SRMU), Lucknow. Built by Sundram Gupta (sundramdotdev) and Praveen Kumar Singh (webdevpraveen).

Interactive Lab Tools

  • DBMS SQL Playground — Write & execute SQL queries online (CREATE, SELECT, INSERT, JOIN) with AlaSQL
  • CPU Scheduling Visualizer — FCFS, SJF, Priority, Round Robin with animated Gantt charts
  • Memory Allocation Simulator — First Fit, Best Fit, Worst Fit algorithms
  • Disk Scheduling Simulator — FCFS, SCAN, C-SCAN, LOOK, C-LOOK
  • Page Replacement Algorithm — FIFO, LRU, Optimal page replacement
  • Banker's Algorithm — Deadlock detection & avoidance
  • Binary Tree Visualizer — Build & traverse (Inorder, Preorder, Postorder, Level-order)
  • Graph Algorithm Visualizer — BFS, DFS, Dijkstra's Shortest Path
  • Linux Terminal Simulator — Practice bash/shell commands in browser
  • Regex Playground — Real-time regular expression testing
  • REST API Playground — Send HTTP requests (GET, POST, PUT, DELETE)
  • Networking Simulator — Network protocol & packet simulation
  • Number System Converter — Binary, Octal, Decimal, Hexadecimal
  • Memory Hierarchy Visualizer — Cache, RAM, storage levels
  • Logic Gates Simulator — AND, OR, NOT, NAND, NOR, XOR circuits
  • Stack & LIFO Visualizer — Push/pop with step-by-step animation
  • Queue & FIFO Visualizer — Enqueue/dequeue operations
  • Linear Algebra Visualizer — Vectors, matrices, transformations
  • Calculus Visualizer — Derivatives & area under curves

Why Bunk & Learn Hub?

Traditional CS education relies on static whiteboards and theoretical lectures to explain dynamic systems like CPU scheduling, memory allocation, and network routing. Students are forced to mentally simulate algorithm behavior over time — which is slow and error-prone.

Bunk & Learn Hub bridges this gap by providing interactive, animated, step-by-step simulations of every major CS concept. You input your own data, watch algorithms execute visually, and get instant results with calculations — all in your browser, no installation needed.

Whether you're preparing for your SRMU Operating Systems lab, DBMS practical exam, or just want to understand how Binary Trees work, this platform has you covered with 20+ free tools.

Key Features

  • DBMS SQL Playground: Execute real SQL queries in-browser. Practice CREATE TABLE, INSERT, SELECT with JOINs, WHERE, GROUP BY, ORDER BY using AlaSQL engine. Perfect for DBMS lab practicals — no MySQL or PostgreSQL installation required.
  • CPU Scheduling: Visualize FCFS, SJF, Priority, and Round Robin algorithms with animated Gantt charts. See waiting time, turnaround time, and completion time calculations.
  • Data Structures: Build Binary Trees and run Inorder, Preorder, Postorder, Level-order traversals. Create interactive graphs and run BFS, DFS, and Dijkstra's algorithm.
  • Linux Terminal: Simulated bash shell in your browser. Practice ls, cd, mkdir, cat, grep, chmod, and more. No VM or dual-boot needed.
  • OS Algorithms: Memory allocation (First Fit, Best Fit, Worst Fit), Disk Scheduling (SCAN, C-SCAN, LOOK), Page Replacement (FIFO, LRU, Optimal), and Banker's Algorithm for deadlock.
  • Developer Tools: Regex Playground with real-time match highlighting. REST API Playground for testing HTTP endpoints.
  • Mathematics: Linear Algebra (vectors, matrices) and Calculus (derivatives, area under curves) with visual representations.
