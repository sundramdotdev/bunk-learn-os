# Project Roadmap

This document outlines the high-level roadmap for Bunk & Learn Hub.

## Phase 1: Operating Systems & Fundamentals (✅ Completed)
- [x] CPU Scheduling Simulator
- [x] Memory Management (First/Best Fit)
- [x] Disk Scheduling 
- [x] Page Replacement
- [x] Banker's Algorithm
- [x] Number System Converter
- [x] Digital Logic & Memory Layouts

## Phase 2: Algorithms & Developer Tools (✅ Completed)
- [x] Binary Tree Traversal Visualizer
- [x] Graph Algorithm Visualizer (BFS, DFS, Dijkstra)
- [x] Browser-based Linux Terminal
- [x] Regex Playground
- [x] REST API Simulator
- [x] Full Networking Simulator Suite (Packet, OSI, TCP, UDP, DNS, HTTP, Routing)

## Phase 3: Future Enhancements (🚧 In Progress / Planned)
- [ ] **Cloud Saves**: Add a lightweight Node.js/Next.js backend allowing students to save their custom graphs or memory layouts via a simple shortlink.
- [ ] **Sorting Algorithms**: Visualizations for Quick, Merge, Heap, and Bubble sort.
- [ ] **Machine Learning Basics**: Interactive Neural Network forward-pass visualizer.
- [ ] **Relational Databases**: SQL playground with an in-memory SQLite WASM database.

We welcome community contributions for Phase 3! Please check the issues tab for "good first issue" tags.
