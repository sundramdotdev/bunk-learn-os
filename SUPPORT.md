# Support

If you need help using Bunk & Learn Hub, have discovered a bug, or want to suggest a new feature, here is how you can reach us:

## 1. Issue Tracker
The primary way to get support is by opening an issue on our [GitHub Repository](https://github.com/sundramdotdev/bunk-learn-os/issues).

Before opening a new issue:
- Search existing issues to see if your problem has already been reported.
- Ensure you are providing enough context (browser version, steps to reproduce, screenshots).

## 2. Feature Requests
We actively welcome feature requests! If you are learning a topic in university and think it would make a great visual module, open a feature request issue. 

## 3. Contact Maintainers
If you need to reach out privately (e.g., for security vulnerability reports), please email sundramdotdev@gmail.com.

## 4. Community
While we do not currently have a dedicated Discord server, you can join discussions in the GitHub Discussions tab of our repository.
