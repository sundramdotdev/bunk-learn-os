# Changelog

All notable changes to this project will be documented in this file.

## [v3.0.0] - 2026-07-13

### Added
- **Data Structures**: Added Binary Tree Visualizer (BST, Traversals).
- **Algorithms**: Added Graph Visualizer (BFS, DFS, Dijkstra).
- **Developer Tools**: Added Linux Terminal Simulator.
- **Developer Tools**: Added Regex Playground.
- **Developer Tools**: Added API Playground (REST Mock Simulator).
- **Computer Networking**: Added Flagship Networking Simulator (Packet, TCP, UDP, DNS, HTTP, IP Routing, Congestion, OSI).
- **Documentation**: Added comprehensive documentation and informational website pages.

## [v2.0.0] - 2025-10-05

### Added
- Memory Allocation Module (First Fit, Best Fit).
- Page Replacement Module.
- Disk Scheduling Module.
- Banker's Algorithm (Deadlock Avoidance).
- Number Systems Converter.

## [v1.0.0] - 2025-01-10

### Added
- Initial CPU Scheduling Visualizer for OS Lab (FCFS, SJF, RR, SRTF).
