# Security Policy

## Supported Versions

Currently, only the latest `main` branch version is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v3.0.x  | :white_check_mark: |
| v2.0.x  | :x:                |
| v1.0.x  | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues. Instead, please report them to [sundramdotdev@gmail.com].

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If you report a vulnerability, you will be acknowledged in our security advisory unless you request otherwise.
